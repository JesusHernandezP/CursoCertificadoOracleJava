In this exercise you have to parse the data variable and assign the values to the person object:
Split the data variable using var array = data.split(",") function.
Set person.name to array[0]
Solution: person.name = array[0];
Set person.lastName to array[1]
Solution: person.name = array[1];
Set person.age to array[2] as integer
Use parseInt(array[2])
Set person.credit to array[6] as float
Use parseFloat(array[6])
Set person.rating to array[7] as a trimmed string
Trim the string using: array[7].trim()
Set person.birthdate to year:array[3], month:array[4]-1 and dayOfMonth:array[5];
For this challenge you need to create a new Date and set the year, month, and day to their respective values.
Remember the resulting date is: October 10th 1982
The month in the date object must be set to 9! (0 based months, 0=January, 12=December)
You can use the date constructor: new Date(year, month, day, 0, 0, 0, 0);

person = {

In this exercise you to modify arrays.
  1. Pop 2 elements from the animals array.
  2. push a number 10 into the numbers array.
  3. Remove the element at index 2 from the floats array using splice.
  4. Replace "yellow" for "orange" from the colors array using splice.
  5. Remove all items from the people array.
  6. Push a function that returns true to the functions array.

To remove an item using splice use:

Array methods:
  • array.pop(): removes and return the last item of the array.
  • array.push(item): insert item at the end of the array.
    item: the item to insert.
  • array.splice(index, itemsToRemove, itemsToInsert...)
       index: the index to remove or insert items
       itemsToRemove: the number of items to remove starting at the index.
       itemsToInsert: none, one or many items to insert at the index. Each item is a separate parameter and you can send as many as you need.

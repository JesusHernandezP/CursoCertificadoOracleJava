Use map - reduce on the items array to get the total.
You can use map reduce technique or a direct redude in this exercise.
Map-Reduce: 
var total = items.map(function(item){
   return item.price;
}).reduce(function(prevVal, item){
   var totalValue = prevVal+item;
   return totalValue;
}, 0);
Direct Reduce: 
var total = items.reduce(function(prevVal, item){
   var totalValue = prevVal+item.price;
   return totalValue;
 }, 0);

Array Reference

array.map(function(item){
  return item.property;
})
This function returns a new array formed of the result of invoking the callback on every element of the array.

array.reduce(function(prevVal, item){
  var totalValue = prevVal+item;
  return totalValue;
}, initialValue)
This function returns a single value with the result of invoking the callback on all the items of the array. The value returned by the callback is the next callback's prevVal. The first execution prevVal is initialValue. The result is the last execution totalValue.

array.filter(function(item){
  return true|false;
})
This functions returns a new array with all the items that returned true when calling the callback function.

array.forEach(function(item){
  //Code
})
This functions executes the callback in all the elements of the array.

array.some(function(item){
  return true|false;
})
This function returns true if the callback function returns true for at least one item in the array.

array.every(function(item){
  return true|false;
})
This function returns true if the callback function returns true for all the items in the array.

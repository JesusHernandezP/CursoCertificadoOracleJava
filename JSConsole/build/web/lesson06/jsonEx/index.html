Set the variables with JSON Strings
Set the variable jsonObject1 to the JSON string of: {name:"John", age: 32}
Solution: var jsonObject1 = "{\"name\":\"John\", \"age\": 32}";
Set the variable jsonArray1 to the JSON string of: [1,2,3]
Solution: var jsonArray1 = "[1,2,3]";
Set the variable jsonObject2 to the JSON string of: {name:"John", age: 32, level:"A", scores:{math:100, history:75}}
Solution: var jsonObject2 = "{\"name\":\"John\", \"age\": 32, \"level\":\"A\", \"scores\":{\"math\":100, \"history\":75}}";
Set the variable jsonArray1 to the JSON string of: [1,2,"a","b",{name:"Ed"}]
Solution: var jsonArray2 = "[1,2,\"a\",\"b\",{\"name\":\"Ed\"}]";
Parse the jsonObject2 variable and set it to the object2 variable.
Solution: var object2 = JSON.parse(jsonObject2);
In order for this to work the previous test must pass.
Remember that in JSON strings the object's attributes must be double quoted!
One simple way to accomplish this is to use JavaScript Strings with a single quote:
'{"name":"John", "age": 32}'

In this exercise you convert the cookies example using local storage.
In the window load listener:
  1. Get the saved value inside the localStorage key: "storedObject".
  2. Parse the stored data using JSON and assign it to storedObject if it is not empty.
In the addProperty function:
  1. add the property to the storedObject variable.
  2. Save the JSON string representation of the storedObject variable in the localStorage with the key: "storedObject".
In the removeProperty function:
  1. Delete the property to the storedObject variable.
  2. Save the JSON string representation of the storedObject variable in the localStorage with the key: "storedObject".

Local Storage Reference

Get a value:
localStorage.getItem("storedObject")
Set a value:
localStorage.setItem("storedObject", value);

JSON API

Parsing:
obj = JSON.parse(data);
Generating JSON
JSON.stringify(obj);

JavaScript Objects

Set a property:
obj[propertyName] = value;
Delete a property:
delete obj[propertyName];

This exercise is composed of 3 sections:

Calculate the total of all items.

  1. Map all items by their price.
  2. Add all the prices using a reduce function.

Calculate the total of all electronics.

  1. Filter all items that are electronics.
    you can use the some array function on the tags array to find out if the tags array contains electronics.
  2. Map the items by their price.
  3. Add all the prices using a reduce function.

Create an object with the count of all the tags.

  1. Use a for each function on all the items.
  2. Use a for each function on all the tags for each item.
  3. Set the allTags[tag] property to 0 if it does not exist.
  4. Use allTags[tag]++ to count the tag found.
